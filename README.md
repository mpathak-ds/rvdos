# Driftless RV-DOS

This is a Disk (not really) Operating System for low-power RISC-V (32) systems developed and maintained by Driftless Software.

# Goal

The goal of RV-DOS is to provide a neat, familiar and usable interface like other DOS systems for low-power RV32 chips and devices - ESPECIALLY
the **WCH CH32V307** chip. It also provides not just the user interface but also the developer interface to mask hardware via abstraction, giving
an easy API to program for.

Another (upcoming) goal is to provide fast real x86 MS-DOS compatibility via optimized emulation.

# Building

Precise instructions are detailed in the root `Makefile`, follow the comments inside it to build and test.
